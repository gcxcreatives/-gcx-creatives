# GCX Creatives Website v2.0

A redesigned, responsive, static website for GCX Creatives. Built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Upload to the existing GitHub repository
1. Extract this ZIP.
2. Open the repository `gcxcreatives/-gcx-creatives`.
3. For each existing file (`index.html`, `styles.css`, `script.js`, `README.md`), open it and choose the pencil/Edit button, or use **Add file → Upload files** to upload the replacements.
4. Upload the new files to the repository root, keeping `assets/` as a folder if present.
5. Commit to `main`. GitHub Pages should redeploy automatically.

**Important:** Do not upload the outer `gcx-creatives-v2` folder. Upload its contents so `index.html` remains at the repository root.
