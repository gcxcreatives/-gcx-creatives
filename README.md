# GCX Creatives Website — v1.0

A lightweight static business website built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## Included
- Responsive one-page website
- Services, industries served, process, pricing, about and booking sections
- Booking enquiry preparation with three contact routes: email, WhatsApp and Instagram DM
- No client portfolio, client logos, testimonials or fabricated case studies
- GCX blue brand palette

## Brand colours
- Midnight Black: `#0A0A0A`
- Graphite Gray: `#2B2B2B`
- Soft Gray: `#D9D9D9`
- Pure White: `#FFFFFF`
- Electric Blue: `#2D7FFF`
- Sky Blue: `#6EA8FF`
- Light Blue Glow: `#89B7FF`

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Create a public GitHub repository named `gcx-creatives`.
2. Upload all files and folders in this project (keep `index.html` at the repository root).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Enquiry flow
The form does not silently claim to submit data to a server. It prepares the enquiry and offers:
- Email to `gcxcreatives@gmail.com`
- WhatsApp to `+91 76708 78399`
- Instagram DM to `@gcx.creatives`

Instagram does not support pre-filling a DM to a profile through a normal public web link. The Instagram button opens the GCX profile; the visitor can copy the prepared enquiry text shown on the page and paste it into the DM.

- Confirm the logo asset is the final approved high-resolution/transparent logo if you have a vector version.
- Test email, WhatsApp and Instagram links on desktop and mobile.
